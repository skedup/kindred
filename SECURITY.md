# Security Policy

## Supported Version

Security fixes currently target the latest `v0.1.x` public preview only.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting or Security Advisories for this
repository. Do not open a public issue for a suspected vulnerability.

Describe the affected version, the safe reproduction shape, and the expected
impact. Do not include Persona text, conversation content, home addresses,
configuration files, debug dumps, session identifiers, account targets,
credentials, private keys, or resident data. We may ask for a minimal synthetic
fixture through the private report.

This project does not operate a hosted service and cannot rotate credentials or
change an operator's OpenClaw instance. If a credential may be exposed, revoke
it with its provider before reporting the software issue.
